# 🔥 Vi điều khiển STC89C52 (họ 8051)

## 🧭 Giới thiệu
Dự án này hướng dẫn học và thực hành với **kit STC89C52** .  
Kit được tích hợp nhiều linh kiện ngoại vi giúp bạn dễ dàng lập trình, mô phỏng và thử nghiệm các bài tập cơ bản đến nâng cao.

| Phần mềm | Mục đích | Ghi chú |
